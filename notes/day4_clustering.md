# ปูพื้นฐาน clustering

## Clustering คืออะไร?

**Clustering** เป็นเทคนิคใน **Unsupervised Learning** ที่ใช้จัดกลุ่มข้อมูลตามความคล้ายคลึงกัน โดยไม่มีการกำหนดเฉลยหรือชื่อกลุ่มล่วงหน้า

> หลักการ: "ข้อมูลที่คล้ายกันควรอยู่กลุ่มเดียวกัน"

### ตัวอย่างการใช้งาน

* จับกลุ่มลูกค้าตามพฤติกรรมการซื้อ
* จับกลุ่มนักเรียนตามผลการเรียน
* จับกลุ่มพื้นที่ตามระดับมลพิษ

### อัลกอริทึมที่นิยม

* K-Means Clustering
* Hierarchical Clustering
* DBSCAN

---

แล้วต่อด้วยตาราง

| หัวข้อ               | Classification        | Clustering                       |
| -------------------- | --------------------- | -------------------------------- |
| ประเภท               | Supervised Learning   | Unsupervised Learning            |
| มีเฉลย (Label)       | มี                    | ไม่มี                            |
| รู้ชื่อกลุ่มล่วงหน้า | รู้                   | ไม่รู้                           |
| เป้าหมาย             | ทำนายกลุ่มของข้อมูล   | ค้นหากลุ่มจากข้อมูล              |
| ตัวอย่าง             | อีเมล Spam / Not Spam | จับกลุ่มลูกค้าตามพฤติกรรมการซื้อ |

# 🎯 K-Means Clustering

K-Means เป็นอัลกอริทึม Clustering ที่ใช้จัดกลุ่มข้อมูลตามความคล้ายคลึงกัน โดยกำหนดให้แต่ละจุดอยู่ในกลุ่มที่มี centroid ใกล้ที่สุด

---

## 📖 คำศัพท์สำคัญ

### Cluster

กลุ่มของข้อมูลที่มีลักษณะคล้ายกัน

### k

จำนวนกลุ่มที่ต้องการแบ่ง

### Centroid

จุดศูนย์กลางของแต่ละกลุ่ม ใช้เป็นตัวแทนของ Cluster

---

## 📌 K-Means ทำงานอย่างไร?

1. กำหนดจำนวนกลุ่ม (k)
2. สุ่มตำแหน่ง Centroid
3. จัดแต่ละจุดให้อยู่กับ Centroid ที่ใกล้ที่สุด
4. คำนวณ Centroid ใหม่จากข้อมูลในกลุ่ม
5. ทำซ้ำจนผลลัพธ์คงที่

---

# k-means clustering

## 🔄 ขั้นตอน K-Means

* สุ่มเลือก k Centroids
* Assign แต่ละ Point ให้ Centroid ที่ใกล้ที่สุด
* คำนวณ Centroid ใหม่
* ทำซ้ำจนไม่มีการเปลี่ยนแปลง

---

## 📊 Elbow Method

ใช้เลือกจำนวนกลุ่ม (k) ที่เหมาะสม

* ทดลองหลายค่า k
* คำนวณ WCSS ของแต่ละค่า
* เลือกจุดที่กราฟเริ่มหักคล้าย "ข้อศอก"

### WCSS คืออะไร?

ผลรวมของระยะห่างระหว่างข้อมูลกับ Centroid ภายใน Cluster

> WCSS ยิ่งน้อย แสดงว่าข้อมูลในกลุ่มยิ่งเกาะกันแน่น
