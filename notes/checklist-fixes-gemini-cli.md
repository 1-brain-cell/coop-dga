# Checklist Roadmap: เพิ่มเนื้อหา Basic Error ใน Day 0

## รายละเอียดการตีความโจทย์
อาจารย์ต้องการให้เพิ่มเนื้อหาเกี่ยวกับข้อผิดพลาดพื้นฐาน (Basic Error) เข้าไปในหน้า `day0.html` โดยเน้นไปที่ส่วนของ Tab "พบกับ python" (Meet Python) เพื่อให้ผู้เริ่มต้นได้เรียนรู้และรับมือกับปัญหาที่พบบ่อย ดังนี้:
- **พิมพ์ผิด (Typos):** เช่น SyntaxError จากการพิมพ์คำสั่งผิด หรือ NameError จากการพิมพ์ชื่อตัวแปรผิด
- **Error:** ข้อผิดพลาดที่เกิดขึ้นขณะรันโปรแกรม (Runtime Errors) เช่น ZeroDivisionError หรือ TypeError
- **Warning:** การแจ้งเตือนที่อาจไม่ทำให้โปรแกรมหยุด แต่เป็นจุดที่ควรระวัง
- **Ignore:** วิธีการรับมือเบื้องต้น หรือการข้ามข้อผิดพลาด (เช่นการใช้ try-except แบบง่ายๆ)
- **หาไฟล์ไม่เจอ (File Not Found):** เช่น FileNotFoundError เมื่อพยายามเปิดไฟล์ที่ไม่มีอยู่จริง

**แนวทางการเขียน:**
- ใช้ภาษาที่เข้าใจง่าย ไม่ซับซ้อน
- มีตัวอย่างโค้ดสั้นๆ ประกอบทุกหัวข้อ
- วางเนื้อหาต่อท้ายสุดของ Tab "พบกับ python"
