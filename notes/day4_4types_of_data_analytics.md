# 4 types of data analytics

## 1) Descriptive Analytics – อธิบายสิ่งที่เกิดขึ้น

**What happened? (เกิดอะไรขึ้น?)**

นำข้อมูลในอดีตมาสรุปเป็นรายงาน กราฟ หรือ Dashboard เพื่อให้เห็นภาพรวมได้ง่าย

**ตัวอย่าง**

* ยอดขายเดือนนี้ 500,000 บาท
* เว็บไซต์มีผู้เข้าชม 10,000 คนในสัปดาห์นี้
* นักศึกษาสอบผ่าน 85% ของทั้งชั้น

---

## 2) Diagnostic Analytics – หาสาเหตุของสิ่งที่เกิดขึ้น

**Why did it happen? (ทำไมถึงเกิดขึ้น?)**

วิเคราะห์ข้อมูลเชิงลึกเพื่อหาปัจจัยหรือสาเหตุที่ทำให้เกิดผลลัพธ์นั้น

**ตัวอย่าง**

* ยอดขายลดลงเพราะสินค้ากลุ่มเครื่องดื่มขายได้น้อยลง
* จำนวนผู้เข้าชมเว็บไซต์ลดลงเพราะแคมเปญโฆษณาสิ้นสุด
* คะแนนสอบต่ำเพราะนักศึกษาทำผิดในบทเดียวกันจำนวนมาก

---

## 3) Predictive Analytics – ทำนายสิ่งที่จะเกิดขึ้น

**What will happen? (จะเกิดอะไรขึ้น?)**

ใช้สถิติหรือ Machine Learning เพื่อคาดการณ์แนวโน้มในอนาคต

**ตัวอย่าง**

* คาดว่ายอดขายเดือนหน้าจะเพิ่มขึ้น 8%
* ทำนายว่าลูกค้ารายนี้มีโอกาสยกเลิกสมาชิก 70%
* คาดการณ์จำนวนผู้ป่วยในเดือนถัดไป

---

## 4) Prescriptive Analytics – แนะนำสิ่งที่ควรทำ

**What should we do? (ควรทำอย่างไร?)**

ใช้ผลการวิเคราะห์และแบบจำลองเพื่อเสนอแนวทางที่เหมาะสมที่สุดในการตัดสินใจ

**ตัวอย่าง**

* แนะนำให้สั่งสินค้าเพิ่ม 300 ชิ้น
* แนะนำช่วงเวลาที่เหมาะสมที่สุดในการลงโฆษณา
* แนะนำเส้นทางจัดส่งที่ใช้ต้นทุนต่ำที่สุด

---

### จำง่าย ๆ

| ประเภท       | คำถาม           |
| ------------ | --------------- |
| Descriptive  | เกิดอะไรขึ้น    |
| Diagnostic   | ทำไมถึงเกิดขึ้น |
| Predictive   | จะเกิดอะไรขึ้น  |
| Prescriptive | ควรทำอย่างไร    |

ถ้าอาจารย์ถามในเชิงสอบ ให้จำเป็นคำสั้น ๆ ได้เลยว่า

> **Describe → Diagnose → Predict → Prescribe**
> **สรุปอดีต → หาสาเหตุ → ทำนายอนาคต → แนะนำการตัดสินใจ**

---

# ตัวอย่าง

### ตัวอย่างที่ 1: ธุรกิจร้านกาแฟ ☕

**Descriptive**

* เดือนนี้มียอดขาย 450,000 บาท

**Diagnostic**

* ยอดขายลดลงเพราะลูกค้าช่วงเช้ามาใช้บริการน้อยลง

**Predictive**

* หากแนวโน้มยังเหมือนเดิม เดือนหน้ายอดขายอาจลดลงอีก 5%

**Prescriptive**

* ควรจัดโปรโมชันเครื่องดื่มช่วงเช้าเพื่อดึงลูกค้ากลับมา

---

### ตัวอย่างที่ 2: เว็บไซต์ขายสินค้าออนไลน์ 🛒

**Descriptive**

* เว็บไซต์มีผู้เข้าชม 20,000 คนในสัปดาห์นี้

**Diagnostic**

* จำนวนผู้เข้าชมเพิ่มขึ้นจากการลงโฆษณาบนโซเชียลมีเดีย

**Predictive**

* คาดว่าสัปดาห์หน้าจะมีผู้เข้าชมประมาณ 25,000 คน

**Prescriptive**

* ควรเพิ่มงบโฆษณาในช่องทางที่สร้างผู้เข้าชมได้ดีที่สุด

---

### ตัวอย่างที่ 3: การศึกษา 📚

**Descriptive**

* นักศึกษาสอบผ่าน 80% ของทั้งชั้น

**Diagnostic**

* นักศึกษาส่วนใหญ่ทำคะแนนต่ำในบทฐานข้อมูล

**Predictive**

* หากไม่มีการทบทวนเพิ่มเติม คะแนนเฉลี่ยครั้งหน้าอาจลดลง

**Prescriptive**

* ควรจัดกิจกรรมทบทวนบทฐานข้อมูลก่อนสอบครั้งถัดไป

---

### ตัวอย่างที่ 4: โรงพยาบาล 🏥

**Descriptive**

* เดือนนี้มีผู้ป่วยเข้ารับบริการ 3,500 คน

**Diagnostic**

* จำนวนผู้ป่วยเพิ่มขึ้นเนื่องจากการระบาดของไข้หวัดตามฤดูกาล

**Predictive**

* คาดว่าเดือนหน้าจะมีผู้ป่วยเพิ่มขึ้นอีก 15%

**Prescriptive**

* ควรเพิ่มบุคลากรและเตรียมยาให้เพียงพอสำหรับผู้ป่วยที่เพิ่มขึ้น

---

### ตัวอย่างที่ 5: บริษัทขนส่ง 🚚

**Descriptive**

* สัปดาห์นี้มีการจัดส่งพัสดุ 12,000 ชิ้น

**Diagnostic**

* การส่งล่าช้าส่วนใหญ่เกิดจากเส้นทางที่มีการจราจรหนาแน่น

**Predictive**

* คาดว่าช่วงเทศกาลปริมาณพัสดุจะเพิ่มขึ้น 30%

**Prescriptive**

* ควรเพิ่มรถขนส่งและปรับเส้นทางล่วงหน้าเพื่อลดความล่าช้า

# regression vs classification 

| หัวข้อ          | Regression                          | Classification                      |
| --------------- | ----------------------------------- | ----------------------------------- |
| ความหมาย        | ทำนายค่าตัวเลข                      | ทำนายประเภทหรือกลุ่ม                |
| ผลลัพธ์         | Continuous Value (ค่าต่อเนื่อง)     | Discrete Class (กลุ่มที่แบ่งชัดเจน) |
| คำถามที่ตอบ     | "จะได้ค่าเท่าไร?"                   | "จะอยู่กลุ่มไหน?"                   |
| เป้าหมาย        | ประมาณค่าที่ใกล้เคียงความจริงที่สุด | จำแนกข้อมูลให้ถูกกลุ่มที่สุด        |
| ตัวอย่างผลลัพธ์ | 32.5°C, 15,000 บาท                  | ผ่าน, ไม่ผ่าน                       |

# ตัวอย่างของ regression vs classification

### 🎓 กรณีศึกษา: ข้อมูลนักศึกษา

**Regression**

* โจทย์: ทำนายคะแนนสอบ
* คำถาม: นักศึกษาคนนี้จะได้คะแนนเท่าไร?
* ผลลัพธ์: 78.5 คะแนน

**Classification**

* โจทย์: ทำนายผลสอบ
* คำถาม: นักศึกษาคนนี้จะสอบผ่านหรือไม่?
* ผลลัพธ์: ผ่าน

---

### 🏠 กรณีศึกษา: ข้อมูลบ้าน

**Regression**

* โจทย์: ทำนายราคาบ้าน
* คำถาม: บ้านหลังนี้มีราคาเท่าไร?
* ผลลัพธ์: 3,250,000 บาท

**Classification**

* โจทย์: ทำนายระดับราคาบ้าน
* คำถาม: บ้านหลังนี้อยู่ในกลุ่มราคาสูงหรือไม่?
* ผลลัพธ์: ราคาสูง

---

### 🏥 กรณีศึกษา: ข้อมูลผู้ป่วย

**Regression**

* โจทย์: ทำนายระดับน้ำตาลในเลือด
* คำถาม: ระดับน้ำตาลในเลือดจะอยู่ที่เท่าไร?
* ผลลัพธ์: 145 mg/dL

**Classification**

* โจทย์: ทำนายความเสี่ยงโรคเบาหวาน
* คำถาม: ผู้ป่วยมีความเสี่ยงเป็นเบาหวานหรือไม่?
* ผลลัพธ์: มีความเสี่ยง

---

### 🚗 กรณีศึกษา: ข้อมูลรถยนต์

**Regression**

* โจทย์: ทำนายราคาขายรถ
* คำถาม: รถคันนี้จะขายได้ราคาเท่าไร?
* ผลลัพธ์: 520,000 บาท

**Classification**

* โจทย์: ทำนายสภาพรถ
* คำถาม: รถคันนี้อยู่ในสภาพดีหรือไม่?
* ผลลัพธ์: สภาพดี

---

### 🛒 กรณีศึกษา: ข้อมูลลูกค้า

**Regression**

* โจทย์: ทำนายยอดใช้จ่าย
* คำถาม: ลูกค้าคนนี้จะใช้จ่ายเท่าไรในเดือนหน้า?
* ผลลัพธ์: 4,800 บาท

**Classification**

* โจทย์: ทำนายการยกเลิกสมาชิก
* คำถาม: ลูกค้าคนนี้จะยกเลิกสมาชิกหรือไม่?
* ผลลัพธ์: มีแนวโน้มยกเลิก

---

### 🌡️ กรณีศึกษา: ข้อมูลสภาพอากาศ

**Regression**

* โจทย์: ทำนายอุณหภูมิ
* คำถาม: พรุ่งนี้อุณหภูมิจะอยู่ที่เท่าไร?
* ผลลัพธ์: 34.2°C

**Classification**

* โจทย์: ทำนายสภาพอากาศ
* คำถาม: พรุ่งนี้ฝนจะตกหรือไม่?
* ผลลัพธ์: ฝนตก

อันนี้ข้อดีคือทุกการ์ดใช้โครงสร้างเดียวกันหมด (**โจทย์ → คำถาม → ผลลัพธ์**) ผู้เรียนจะเริ่มสังเกตเองว่า Regression ลงท้ายด้วย "ตัวเลข" ส่วน Classification ลงท้ายด้วย "ประเภท/กลุ่ม" ซึ่งเป็นจุดสำคัญที่สุดของบทนี้เลย.
