  - *จุดแก้ไข*: ฟังก์ชัน `draw()` และระบบการเก็บพิกัดในด่านที่ 7

## 🐍 3. หน้า `day1.html` (Python & Data Exploration)

- [x] **[Code Quality] ป้องกันข้อผิดพลาดดัชนีสีเกินขอบเขตใน K-Means (Array Index Overflow)**
  - *ปัญหา*: ตัวแปร `kmColors` เก็บสีไว้ 5 สี หากในอนาคตมีผู้ขยายแถบสไลเดอร์ K ให้เลือกได้มากกว่า 5 กลุ่ม (เกิน `kmColors.length`) โค้ดจะพ่นค่า `undefined` และสไตล์พัง
  - *จุดแก้ไข*: การกำหนดสีจุด `ctx.fillStyle` ในฟังก์ชัน `drawKMeans()`
  - *แนวทาง*: นำ Operator Modulo (`%`) มาช่วยครอบดัชนี เพื่อให้สุ่มวนใช้สีเก่าได้เมื่อกลุ่มเกินกำหนด:
    ```javascript
    ctx.fillStyle = kmColors[i % kmColors.length];
    ```

- [x] **[UI/UX] ป้องกันปัญหาช่องว่างส่วนเกินในการตรวจสอบ Key ของ Dictionary**
  - *ปัญหา*: การป้อนข้อมูล Key ใน Dictionary Playground หากพิมพ์เคาะเว้นวรรค เช่น `"name "` จะถูกบันทึกเป็นคนละคีย์กับ `"name"` และค้นหาไม่เจอ
  - *จุดแก้ไข*: ฟังก์ชัน `dictAdd()` และ `dictLookup()`
  - *แนวทาง*: ใส่ฟังก์ชัน `.trim()` ให้กับ Key ก่อนนำไปตรวจสอบเปรียบเทียบในอาร์เรย์

- [x] **[UI/UX] แก้ไขรูปทรงพิกัดและเส้นชี้นำทางของ Flowchart ในส่วน if-elif-else ให้ถูกต้องตามทฤษฎีและไม่ทับซ้อน**
  - *ปัญหา*: แผนภาพ Flowchart เงื่อนไขในหน้า `day1.html` มีปัญหาเรื่องตำแหน่งกล่องและข้อความทับซ้อนกัน โดยป้ายข้อความ `"score >= 70?"` และ `"ไม่"` ซ้อนกัน, กล่องของเกรด B (`cb-a70`) ลอยขึ้นไปทับกล่องเกรด A ในแกน Y=160 (ทำให้เห็นเป็นกล่องเปล่าลอยอยู่), และเส้นโยงทับซ้อน
  - *จุดแก้ไข*: แท็ก SVG ของแผนภาพ `#cond-flow` ในหน้า `day1.html`
  - *แนวทาง*: คำนวณพิกัดตำแหน่งโหนดและแนวเส้นเชื่อมต่อใน Inline SVG ใหม่ทั้งหมด ปรับกล่องเกรด B ไปที่ระดับ Y=210, ปรับป้ายกำกับ "ใช่/ไม่" และตัวหนังสือเงื่อนไขให้อยู่กึ่งกลางรูปทรงข้าวหลามตัดพอดี เพื่อการจัดเรียงที่สวยงามและตรงตามหลักการออกแบบสัญลักษณ์

- [ ] **[Bug - UI] แก้ไขกล่องคำแนะนำ String Slicing (slice-tip) ที่ไม่ยอมตัดบรรทัดเมื่อใส่ `<br>`**
